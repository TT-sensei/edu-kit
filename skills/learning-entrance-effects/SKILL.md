# Learning Entrance Effects

## いつ使うか

教材の初回開始、新単元、新ステージ、新しい世界への移動など、意味のある節目に短い入口演出を使うときに限って使用する。

## 最初に確認するもの

1. 演出が学習への気持ちを切り替える意味を持つか
2. 表示頻度: 初回、セッション初回、単元初回など
3. 演出なしでも教材を完全に利用できるか
4. `edu-effects`の実在する入口演出

## 使用候補

- `logo-draw`: 教材・研究所の初回入口
- `counter`: 計測やチャレンジ開始
- `curtain`: 新ステージ・冒険マップ
- `typewriter`: 短い導入メッセージ
- `world-intro`: 理科・社会・物語型教材の静かな導入

## 手順

1. 通常の問題遷移やホーム復帰では使わない。
2. 原則1〜2秒程度にし、スキップ操作とEscape終了を用意する。
3. `prefers-reduced-motion: reduce`では省略して本編を即表示する。
4. JavaScript停止時でも本編が見える構造にする。
5. 演出中に本編を準備し、終了後すぐ学習できるようにする。
6. 音を必須にせず、毎回表示を標準にしない。
7. 再利用可能な実装はedu-kitではなく`edu-effects`へ還元する。

## 完了条件

- 演出に学習上の場面転換の意味がある。
- スキップでき、reduced motionでは即開始できる。
- 演出失敗・JavaScript停止でも本編を利用できる。
- 通常の問題遷移、ホーム復帰、再挑戦では表示されない。
- 実在するCSS・JSだけを利用している。
