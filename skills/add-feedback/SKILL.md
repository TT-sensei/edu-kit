# Add Learning Feedback

## 目的
正誤を知らせるだけでなく、子どもの次の学習行動につながるフィードバックを作る。

## 原則
- 正解: 短く肯定し、テンポを止めない。
- 不正解: 強い否定で終わらせず、再挑戦できる状態を保つ。
- 必要に応じて「おしい」「ここを見てみよう」「もういちど」など次の行動を示す。
- 色・音・アニメーションの一つだけに意味を依存しない。

## 手順
1. `edu-components` の正誤イベントを確認する。
2. `edu-effects` で実在するフィードバック表現を確認する。
3. 音が必要な場合だけ `sounds-recipe-` の実在IDを確認する。
4. ナビキャラを使う場合は `add-navi-character` に従う。
5. `prefers-reduced-motion` と音量・ミュートを考慮する。

## 避ける
- 不正解で進行不能になる
- 長い演出で問題テンポを止める
- 大きな×だけで終わる
- 毎回同じ強さの祝福演出を出す
