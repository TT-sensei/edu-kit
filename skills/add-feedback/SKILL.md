# Add Learning Feedback

## いつ使うか

正解・不正解・ヒント・再挑戦・達成の反応を、次の学習行動につながる形で追加または改善するときに使う。

## 最初に確認するもの

1. 現在の正誤判定と進行ロジック
2. `edu-components`の正誤イベント正本
3. `edu-effects`のCSS本体とカタログ
4. 不正解後に再挑戦させるか、正答を示して次へ進むか

## 使用候補

- `edu-components`: 正誤イベントと採点
- `edu-effects`: 実在するフィードバック表現
- `sounds-recipe-`: 音が必要な場合だけ
- `navi-character-`: キャラを添える場合だけ`add-navi-character`も使う

## 手順

1. 正解は短く肯定し、問題テンポを止めない。
2. 不正解は強い否定で終わらせず、次の行動を短文で示す。
3. 色・音・アニメーションの一つだけに意味を依存させない。
4. 連続入力や二重回答を防ぎつつ、進行不能にしない。
5. 音量・ミュートと`prefers-reduced-motion`を考慮する。
6. 正解・不正解の両方から次問または再挑戦へ進めるか確認する。

## 完了条件

- 正解時にテンポよく次へ進める。
- 不正解時に停止せず、次の行動が分かる。
- 音なし、色の識別なし、reduced motionでも意味が伝わる。
- 使用イベント、CSSクラス、音ID、画像URLが実在する。
- 毎回答で過剰な祝福演出を出していない。
