# Add Rewards

## 目的
バッジ、コレクション、レベル等を、学習を続けたくなる補助として導入する。

## 原則
- ご褒美を得るためだけの作業にしない。
- 学習入口を最優先し、ご褒美エリアは二次導線にする。
- 厳しすぎる獲得条件を避け、小さな成長も見えるようにする。
- 他者との競争より自分の進歩を示す。

## 手順
1. 何を称えるのか決める。例: 初回挑戦、継続、正答、再挑戦、単元完了。
2. `edu-components` の Progress / Achievement / Badge 等から必要なものを選ぶ。
3. `edu-assets` で実在する画像とレアリティを確認する。
4. 獲得演出は特別感を出しつつ、次の学習へ戻りやすくする。
5. 保存には教材固有namespaceを使う。

## 避ける
- トップ画面でバッジ一覧が学習ボタンより目立つ
- レア報酬を極端に取りにくくする
- 学習と無関係な連打や滞在時間だけで報酬を与える
- 大量の未獲得要素で子どもを圧倒する
