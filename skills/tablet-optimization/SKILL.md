# Tablet Optimization

## いつ使うか

学校のPC・タブレット・スマホで、教材の主要操作と表示を最適化するときに使う。特にタブレット横向きとPCを優先する。

## 最初に確認するもの

1. 保護対象となる学習内容と判定ロジック
2. スマホ、タブレット縦・横、一般的なPCでの現状
3. 問題文・観察対象・主要ボタンの優先順位
4. タッチ、マウス、キーボードの操作方法
5. 画面内に収める情報と、補足としてスクロールしてよい情報

## 使用候補

- 教材固有CSSのmedia query
- edu-effectsの実在するレイアウト・ボタン・フォーカス表現
- タップ代替を持つedu-componentsの問題形式

## 手順

1. タブレット横向きでは、問題・観察対象・主要操作・現在地を基本1画面に配置する。
2. PCで左右が空きすぎる場合は、学習領域を適切に拡張する。
3. スタート画面のタイルやカードを大きくしすぎず、選択中のモードを見た目で示す。
4. 問題文、式、選択肢を絵文字・キャラクター・装飾より読みやすくする。
5. タップ対象の大きさと間隔を確保する。
6. hoverだけに意味を持たせず、フォーカスを見えるようにする。
7. 長押し・ドラッグだけを必須にせず、タップ代替を用意する。
8. 学習に不要な固定要素を増やさない。
9. 各確認幅で文字切れ、横スクロール、固定要素の重なり、レイアウトシフトを確認する。

## 完了条件

- タブレット横向きで問題文と主要操作が同時に見やすい。
- シミュレーターでは条件・観察対象・結果が関係づけて見える。
- ボタンが小さすぎず、タッチで誤操作しにくい。
- キャラ・バッジがPCで過度に拡大されない。
- スマホ、タブレット縦・横、PCで横スクロールが意図せず発生しない。
- タッチ、マウス、必要に応じてキーボードで操作できる。
- 結果画面から次の学習またはホームへ戻れる。
