# Tablet Optimization

## いつ使うか

学校のPC・タブレット・スマホで、教材の主要操作と表示を最適化するときに使う。特にタブレット横向きとPCを優先する。

## 最初に確認するもの

1. 保護対象となる学習内容と判定ロジック
2. スマホ、タブレット縦・横、一般的なPCでの現状
3. 問題文・選択肢・主要ボタンの優先順位
4. タッチ、マウス、キーボードの操作方法

## 使用候補

- 教材固有CSSのmedia query
- `edu-effects`の実在するレイアウト・ボタン・フォーカス表現
- タップ代替を持つ`edu-components`の問題形式

## 手順

1. 主要学習領域に適切な最大幅を設定する。
2. PCで左右が空きすぎる場合は、学習領域を適切に拡張する。
3. タップ対象の大きさと間隔を確保する。
4. hoverだけに意味を持たせず、フォーカスを見えるようにする。
5. 長押し・ドラッグだけを必須にせず、タップ代替を用意する。
6. 学習に不要な固定要素を増やさない。
7. 各確認幅で文字切れ、横スクロール、固定要素の重なりを確認する。

## 完了条件

- 問題文と選択肢が同時に見やすい。
- ボタンが小さすぎず、タッチで誤操作しにくい。
- キャラ・バッジがPCで過度に拡大されない。
- スマホ、タブレット縦・横、PCで横スクロールが意図せず発生しない。
- タッチ、マウス、必要に応じてキーボードで操作できる。
- 結果画面から次の学習またはホームへ戻れる。
