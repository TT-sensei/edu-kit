# Improve Existing App

## 目的
既存教材の学習内容と動作を守りながら、必要な部分だけを改善する。

## 最重要
**変更前に、壊してはいけないものを特定する。**

## 手順
1. 現在の画面構成、問題データ、判定、進行、保存、ナビゲーションを調査する。
2. ユーザーが「触らない」と指定した領域を保護対象として明文化する。
3. 問題データ・正答・判定ロジックは、依頼に必要でない限り変更しない。
4. 改善対象をUI、導線、演出、レスポンシブ等に限定する。
5. 共通部品を導入する場合も既存挙動との互換性を優先する。
6. 大規模な全面書き換えより、小さく追跡可能な変更を優先する。
7. 変更後、開始→出題→正解→不正解→次問→結果→ホーム復帰まで確認する。
8. 保存機能がある場合は既存データを壊さないことを確認する。
9. `final-review` を実行する。

## 回帰防止
- 正解して進めるか
- 間違えても停止しないか
- ホームへ戻れるか
- リロード後も破綻しないか
- タッチとマウスの両方で操作できるか
- 既存の問題数・正答・学習順序が意図せず変わっていないか
