# Create Learning App

## 目的
新しい小学校向けWeb教材を、見た目ではなく学習体験から設計する。

## 手順
1. 学年・教科・単元・身につけたい力を1文で定義する。
2. 子どもが繰り返す行動を定義する。例: 見る→考える→答える→反応を見る→次へ。
3. 問題形式と1回の問題数を決める。
4. `edu-components`から必要な部品だけを選ぶ。
5. 誤答時に次の試行へつながるフィードバックを設計する。
6. 保存・進捗が学習に必要な場合だけ追加する。
7. `edu-effects`、音、バッジ、ナビキャラは学習骨格完成後に選ぶ。
8. HTML/CSS/Vanilla JS、GitHub Pagesで直接動く構成を優先する。
9. 最後に `final-review` を実行する。

## 完了条件
- 最初の画面から学習開始方法が分かる
- 教師の追加説明なしでも基本操作が理解できる
- 正誤だけでなく次の行動が分かる
- ご褒美やキャラクターより問題が主役
- PC・タブレット・スマホで主要操作が可能
