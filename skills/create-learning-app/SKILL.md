# Create Learning App

## いつ使うか

新しい小学校向けWeb教材を、学習目標と学習行動から設計・作成するときに使う。

## 最初に確認するもの

1. `DESIGN-PRINCIPLES.md`
2. `AI-GUIDE.md`
3. 学年・教科・単元・身につけたい力
4. 1回の問題数、保存の要否、利用端末

## 使用候補

- `edu-components`: 出題、判定、進行、保存
- `edu-effects`: 学習UIと必要最小限の演出
- `sounds-recipe-`: 効果音が学習を補助する場合だけ
- `edu-assets`: 学習上意味のある報酬が必要な場合だけ
- `navi-character-`: 案内・励ましが必要な場合だけ

## 手順

1. 身につけたい力を1文で定義する。
2. 子どもが繰り返す行動を定義する。例: 見る→考える→答える→反応を見る→次へ。
3. 問題形式と1回の問題数を決める。
4. `edu-components`から必要な部品だけを選び、正本で実在を確認する。
5. 誤答時に次の試行へつながるフィードバックを設計する。
6. 保存・進捗が学習に必要な場合だけ追加する。
7. 学習骨格の完成後にUI、音、報酬、ナビキャラを選ぶ。
8. HTML/CSS/Vanilla JSでGitHub Pagesから直接動く構成にする。
9. `final-review`を実行する。

## 完了条件

- 最初の画面から学習開始方法が分かる。
- 教師の追加説明なしでも基本操作が理解できる。
- 正誤だけでなく次の行動が分かる。
- ご褒美やキャラクターより問題が主役になっている。
- PC・タブレット・スマホで主要操作が可能。
- 使用API・クラス・ID・URLの実在を正本で確認済み。
