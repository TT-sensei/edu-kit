# Add Navi Character

## 目的
ナビキャラクターを、教材の主人公ではなく学習のそばで励ます存在として導入する。

## 原則
- 学習が主役。キャラクターは「そっと」置く。
- キャラクター名は通常UIに表示しない。
- 画面を占有する大きな立ち絵を常用しない。
- 正誤、励まし、達成、開始案内など意味のある場面で使う。

## 推奨配置
- トップ: 必要なら集合画像1枚。学習開始ボタンより目立たせない。
- 問題中: 常時表示する場合は小さく、問題文・選択肢を圧迫しない。
- 正誤: キャラ + 「正解！」「もういちど！」など短文。
- 正誤フィードバックの基準サイズ: 約52px。画面構成に応じて微調整する。
- 達成: 通常時より少し強い表現を許容する。

## 実装
1. `navi-character-` の `catalog.json` とAIガイドで実在画像を確認する。
2. 用途に合う pose / expression を選ぶ。
3. 複数キャラを使う場合はランダム表示も検討する。
4. altを適切に設定し、装飾のみなら空altを検討する。
5. 画像読み込み失敗で学習自体が止まらないようにする。

## 避ける
- 問題より大きいキャラクター
- 毎問派手に切り替わる演出
- キャラ紹介が学習開始より先に続く構成
- 名前ラベルの常時表示
- 正誤情報をキャラ画像だけに依存すること
