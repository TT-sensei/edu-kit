# Add Navi Character

## いつ使うか

ナビキャラクターを、案内・励まし・正誤・達成の補助として教材へ導入するときに使う。

## 最初に確認するもの

1. NAVI-CHARACTER-GUIDELINES.md
2. navi-character-のcatalog.jsonとAIガイド
3. キャラクターを置く場面と、その場面で必要な学習上の意味
4. 問題文・観察対象・選択肢・開始ボタンの優先順位
5. Web版画像の有無

## 使用候補

- トップ：必要なら集合画像1枚
- 問題中：小さな案内・励まし
- 正誤：キャラ + 短文、画像は約52px基準
- 達成：通常時より少し強い表現

## 手順

1. カタログでcharacter ID、pose、expression、画像パスの実在を確認する。
2. Web表示ではassets/web/以下の軽量WebPを先に探し、なければ原本を使う。
3. 教材側の1か所にIDとURLを定義し、パスを散在させない。
4. トップ画面では6人の集合画像1枚を第一候補にする。
5. 複数キャラを使う場合は、場面の意味を保ったランダム表示を検討する。
6. キャラクター名は通常UIに表示しない。
7. 装飾画像は空alt、意味を補う画像は簡潔なaltを設定する。
8. 読み込み失敗時も学習を継続できるようにする。
9. 問題文・観察対象・選択肢を圧迫していないか各画面幅で確認する。

## 完了条件

- キャラクターより学習入口、問題、観察、操作が目立つ。
- 使用画像と軽量版の有無をカタログで確認している。
- 正誤情報を画像だけに依存していない。
- 名前ラベルを常時表示していない。
- 毎問の派手な切替や大きな立ち絵がない。
- 画像失敗時も開始・回答・進行・ホーム復帰ができる。
