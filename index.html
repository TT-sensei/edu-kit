04 / CONNECTION

4資産は、イベントでつなぐ

Managerの中に音やCSSを混ぜません。ロジックがイベントを発火し、教材側が演出・音・画像を呼び出します。

イベント対応表を見る
event-connection.js
// 正解イベントをひとつの接続点に
document.addEventListener(
  EDU_EVENTS.CORRECT,
  () => {
    score.correct();
    EduEffects.play(feedback,
      'effect-correct-pop');
    playRecipe('correct');
  }
);

06 / RULES

迷わせないためのルール

DO

必要なものだけ使う

4資産すべてを読み込まず、学習目標に必要な部品だけを選びます。

CHECK

実在を確かめる

READMEだけで判断せず、実装・カタログ・公開ファイルを確認します。

KEEP

教材固有データは教材側へ

問題文、達成条件、画面文言は共通Managerに混在させません。

AVOID

推測して作らない

存在しないAPI、CSSクラス、音ID、画像URLをでっち上げません。
